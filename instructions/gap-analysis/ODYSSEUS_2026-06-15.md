## Short answer

Carina now matches Odysseus on the named workspace surfaces (cookbook, research, compare, documents, notes, images, email triage, calendar view) while remaining stronger as a runtime and platform.

Odysseus still leads on full CalDAV calendar sync, custom theme authoring, and SaaS marketing polish. Carina leads on MIT licensing, channel breadth, multi-tenancy, Scout security, and domain packs.

The gap is narrow: mostly CalDAV, per-tenant email routing, and go-to-market presentation.

## What Odysseus is selling

From the live pages, Odysseus is marketed as:

- A self-hosted AI workspace running on your hardware
- Chat and autonomous agents
- Tools and MCP
- Cookbook for model discovery and one-click serving
- Email assistant
- Deep research
- Compare
- Memory
- Skills that evolve
- Documents
- Notes and tasks
- Image gallery
- Themes

The pricing page currently shows clear SaaS-style tiers, but checkout is not connected yet. The public docs page says the first product path is still a quickstart-style route.

## Bottom line from the table

Odysseus is still ahead on CalDAV calendar integration, custom theme packs, and consumer-style product marketing.

Carina is ahead as a runtime and platform: MIT license, channels, Scout, hosted/ops architecture, and a complete workspace layer for operator and hosted users.

## What Carina already matches

- Autonomous task execution
- Persistent memory with semantic search
- Skill writing and skill curator flows
- Provider switching during a session
- Tool execution across web, files, shell, HTTP, email, code, browser, and MCP
- Vertical skill packs and multiple channel adapters
- Hosted mode, commercial add-ons, optional Scout security
- Unified workspace: notes, documents, images, email, calendar, memory, packs
- Named CLI/gateway features: cookbook, research, compare
- Node host daemon and device pairing
- MIT commercial story on CLI, docs, and web UI
- Email triage workspace on inbound webhook mail
- Light/dark themes synced across chat and workspace

## Where Carina is still behind Odysseus

- CalDAV calendar sync (Radicale, Nextcloud, Apple, Fastmail)
- Custom theme authoring (agent-created themes)
- Per-tenant inbound email routing on hosted (instance inbox today)
- Odysseus-level visual marketing and onboarding funnel

## Where Carina is ahead

- Channel breadth
- Security and governance through Scout
- Commercial flexibility (MIT licensing)
- Domain pack structure for vertical products
- Hosted and self-hosted boundaries
- Ops and tenant architecture
- Node pairing for multi-device self-hosted setups

## Verdict

**Is Carina the same kind of product as Odysseus?** Very close on workspace surfaces; still different on go-to-market and CalDAV/themes depth.

**Does Carina have the runtime foundation to match or exceed Odysseus?** Yes.

**Does Carina have the workspace foundation?** Yes for operator and hosted BYOK users.

Remaining work is incremental:

1. CalDAV calendar sync
2. Per-tenant inbound email on hosted
3. Optional custom theme packs
4. Keep kernel/MIT/channel/security story as the commercial edge

## Practical conclusion

Carina should present `/workspace` as the unified product entry for both self-hosted operators and BYOK hosted tenants. Use MIT licensing, Scout, and channels as the commercial edge. Treat CalDAV and per-tenant email as the next parity items if Odysseus comparison matters for sales.
