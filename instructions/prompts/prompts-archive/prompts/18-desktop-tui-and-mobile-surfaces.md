# Prompt 18 - Desktop, TUI, and Mobile Surfaces

You are working in the Carina repository.

Goal: evaluate and adopt the extra user surfaces that the source agents ship.

Read first:
- `instructions/prompts/researched_gap/agent_research/UI-CLI-GUI-REPORT.md`
- the current Carina surface code

Assess and implement the missing surface work:
- CLI or TUI patterns that improve direct terminal use
- richer desktop support if it adds real value
- a mobile companion or pairing model if the platform needs it
- cleaner session or message handling across surfaces

Do not add a surface just because another agent has one. Add it if it meaningfully improves adoption, control, or daily use.

Acceptance criteria:
- the team has a written decision on which surfaces to adopt now
- any implemented surface has a real path from start to use
- surface-specific state is not duplicated wildly
