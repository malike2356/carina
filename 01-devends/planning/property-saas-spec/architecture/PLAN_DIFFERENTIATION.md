## Upgrade Triggers (When Users Hit Each Ceiling)

| Ceiling | Triggers Upgrade To | Reason |
|---|---|---|
| Hit 5K token limit | Free → Pro | User is actively using Carina. £20 is the logical next step. |
| Hit 50K token limit | Pro → Pro+ | Heavy user. Also hits the 10-doc upload limit. |
| Want to train Carina on own docs | Pro → Pro+ | Train My AI is locked below Pro+. Once they outgrow Pro, this unlocks. |
| Want better model (Anthropic) | Pro+ → Ultra | Pro+ is DeepSeek + OpenAI. Need Ultra for Anthropic + BYOK. |
| Running a team or business | Ultra → Enterprise | Need multiple users, SSO, SLA, white-label. |
| Power user hitting 150K tokens | Pro+ → Ultra | 150K is generous. If they exhaust it, they're a professional. |
| Want API access at scale | Pro+ → Ultra | API rate limits increase significantly. |
| Need compliance/audit | Pro+ → Ultra | 30-day audit log vs 90-day. Enterprise gets 365-day. |

## Core Strategy

**Free** - Try Carina. See what's possible. Hit the limit, want more.
**Pro** - Individual landlord or casual investor. Enough tokens, basic analysis. But no training.
**Pro+** - Sweet spot. Train Carina. Upload docs. Better models. API access. Most users will land here.
**Ultra** - Power user. Needs BYOK, best models, unlimited everything.
**Enterprise** - Agency, firm, housing association. Multi-user, white-label, resell, SLA.

The hard gate between Pro and Pro+ is **Train My AI**. Most power users will hit Pro's limits and the only way to get what they really want (Carina trained on THEIR knowledge) is to go Pro+. That's a £40/mo jump - significant but justified.

Goal: 50% of paid users on Pro+, 30% on Pro, 15% on Ultra, 5% Enterprise.
