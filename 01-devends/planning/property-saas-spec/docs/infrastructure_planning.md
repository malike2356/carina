### The Shared Auth Layer                                                                                                                                                                                                                     
                                                                                                                                                                                                                                              
This is the most important architectural decision. Both apps need to read and write to the same users table. Two options:                                                                                                                     
                                                                                                                                                                                                                                              
Option A: Same database, shared users table (Recommended)                                                                                                                                                                                     
- Carina and Propreneur connect to the same PostgreSQL database                                                                                                                                                                               
- users table is shared - both apps read/write it                                                                                                                                                                                             
- token_purchases, usage_log also shared - Carina owns the writes, Propreneur can read                                                                                                                                                        
- Propreneur's existing tables stay in the same database, prefixed or separate schema                                                                                                                                                         
- Simplest, most reliable, zero sync overhead                                                                                                                                                                                                 
                                                                                                                                                                                                                                              
Option B: Separate databases, API-based auth sync                                                                                                                                                                                             
- Carina has its own database, Propreneur has its own                                                                                                                                                                                         
- Auth is managed through Laravel Sanctum or a shared auth microservice                                                                                                                                                                       
- Carina exposes an API that Propreneur calls to check token balances                                                                                                                                                                         
- More complex, more failure points, but cleaner separation                                                                                                                                                                                   
                                                                                                                                                                                                                                              
Go with Option A. Same database, shared users table. It's simpler, faster, and Carina and Propreneur are part of the same VERLOX ecosystem - they don't need to be fully decoupled.
