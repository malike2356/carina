    Yes. The website literally says "Carina Core is free and open source" and lists features that have nothing to do with property:
    
    - Persistent memory
    - Self-writing skills
    - Real tool execution
    - Switch providers mid-conversation
    - Every channel, one agent
    - Local first, no telemetry
    
    None of that is property-specific. The property-uk vertical skill pack is one module bolted onto a general-purpose agent framework. It's like saying "can Chrome be used for anything other than Google search?"; the browser is general-purpose; the default homepage just happens to be Google.
    
    The real question is whether Carina's general-purpose toolset is as deep as Hermes'. Based on the comparison table and what I've seen of the architecture:
    
    - It has the agentic loop, memory, skills, and multi-channel messaging; that's a general-purpose agent
    - What it LACKS compared to Hermes is breadth of pre-built tools and skills (no browser, no subagent delegation, no cron chaining, no 70+ skill library)
    - What it GAINS is the Scout security layer and the property domain knowledge
    
    So the honest answer: Carina is a general-purpose agent that happens to be marketed for property because that's where the money is. You could build any vertical on it. The trade-off is you'd be starting from a smaller tool library but with better security from day one.
