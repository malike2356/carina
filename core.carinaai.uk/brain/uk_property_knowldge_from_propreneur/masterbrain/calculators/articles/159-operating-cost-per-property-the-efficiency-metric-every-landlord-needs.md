# Operating Cost per Property: The Efficiency Metric Every Landlord Needs

Published: Mon, 22 Nov 2027 09:00:00 +0000
Category: Calculations
Slug: operating-cost-per-property-the-efficiency-metric-every-landlord-needs

---

Operating cost per property is your total annual operating expenses divided by the number of properties. It tells you how much each property costs to run. If your costs per property are above the market average, you have an efficiency problem.\n\nFor a portfolio of five BTLs with total operating costs of £18,000, the average cost per property is £3,600 a year. That is £300 a month per property. If similar properties in your area cost £2,500 a year to run, yours are expensive.\n\nThe operating cost per property helps you identify which properties are dragging down your portfolio efficiency. If one property costs £5,000 to run while others cost £3,000, that property needs attention. It might be older, less efficient, or simply in a higher-cost area.\n
Track operating cost per property annually. If it is rising faster than inflation, investigate why. The answer might save you thousands.

**The formula**

```
Average OpEx = Total Operating Costs / Number of Properties
```

**Why this matters**

Operating cost per property reveals which properties are efficient and which are not. Track it annually. If costs rise faster than inflation, investigate the cause.
