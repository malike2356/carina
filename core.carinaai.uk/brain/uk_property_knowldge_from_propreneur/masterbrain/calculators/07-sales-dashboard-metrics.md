# Sales Dashboard Metrics - Property Sourcing Business

## Purpose

A weekly sales dashboard tracks activity volume and conversion at each stage of the deal pipeline. By measuring consistently, you can identify exactly where bottlenecks are occurring and correct them quickly.

---

## The 7 Core Sales Metrics

| # | Metric | What It Measures |
|---|---|---|
| 1 | Number of Calls Made to Estate Agents | Top-of-funnel activity - deal flow generation |
| 2 | Number of Viewings Booked | Conversion from calls to viewed properties |
| 3 | Number of Offers Submitted | Deal assessment conversion - how many pass analysis |
| 4 | Number of Offers Accepted | Success rate of negotiated offers |
| 5 | Number of Calls / Appointments with Investors | Investor pipeline activity |
| 6 | Property Deals Sold | Revenue-generating completions |
| 7 | Cash Collected in the Bank | Actual cash realised (lagging indicator) |

## Conversion Rate Analysis

### Funnel Stage Conversion Targets

```
Calls to Agent → Viewing Booked:       15-25%
Viewings → Offers Submitted:            30-50%
Offers Submitted → Offers Accepted:     10-20%
Accepted Offers → Deals Sold:          80-100%
Investor Calls → Deals Sold:           20-40%
```

### How to Calculate Your Own Rates

```
Call-to-Viewing Rate = Viewings / Calls × 100
Viewing-to-Offer Rate = Offers / Viewings × 100
Offer-to-Acceptance Rate = Accepted / Offers × 100
Investor Appointment-to-Sale Rate = Sales / Investor Appointments × 100
```

---

## Pipeline Value Calculation

At any given week, your pipeline value is:

```
Pipeline Value = (Offers Accepted × Average Deal Fee) + (Deals In Progress × Average Deal Fee × Completion Probability)
```

Example:
- 3 offers accepted × £4,500 fee = £13,500 committed pipeline
- 2 deals with investors in final stage × £4,500 × 80% = £7,200 probable
- **Total pipeline: £20,700**

## Leading vs Lagging Indicators

| Indicator Type | Metric | Why It Matters |
|---|---|---|
| Leading | Calls to agents | Predicts deal flow in 4-8 weeks |
| Leading | Viewings booked | Predicts offers in 1-4 weeks |
| Leading | Investor appointments | Predicts sales in 1-3 weeks |
| Lagging | Deals sold | Confirms past activity converted |
| Lagging | Cash collected | Revenue realised, may lag deal by 2-8 weeks |

**Key principle:** If you want more deals next month, increase leading indicators this week. Watching lagging indicators tells you what happened - leading indicators tell you what will happen.

## Bottleneck Diagnosis

| Symptom | Likely Cause | Corrective Action |
|---|---|---|
| Many calls, few viewings | Not enough urgency communicated, wrong agents | Improve call script, target different agents |
| Many viewings, few offers | Poor deal analysis, wrong areas | Review offer criteria, improve due diligence |
| Many offers, low acceptance | Offering too low, poor negotiation | Adjust offer price, improve rapport with agents |
| Offers accepted, not sold | Investor list too thin, wrong deals | Grow investor database, better deal packaging |
| Deals sold, cash delayed | Slow solicitors, investor finance issues | Push completion timelines, pre-qualify investors |

## Revenue Goal Calculation

### Working Backwards from Income Target

```
Monthly Revenue Target = £10,000

Average Deal Fee = £3,500

Deals Required Per Month = £10,000 / £3,500 = 2.9 → 3 deals/month

Acceptance Rate = 15%
Offers Required = 3 / 0.15 = 20 offers/month

Viewing-to-Offer Rate = 40%
Viewings Required = 20 / 0.40 = 50 viewings/month

Call-to-Viewing Rate = 20%
Calls Required = 50 / 0.20 = 250 calls/month → ~13 calls/working day
```

### Activity Dashboard Summary
| Goal | Required Activity |
|---|---|
| £10,000/month revenue | 3 deals/month |
| 3 deals/month | 20 offers/month |
| 20 offers/month | 50 viewings/month |
| 50 viewings/month | 250 agent calls/month |

## Monthly Review Questions

Ask these questions at the end of every month:

1. What was my total activity volume this month?
2. Where is the biggest gap in my conversion funnel?
3. How many new investors did I add to my database?
4. How many deals did I complete vs my target?
5. What is my average fee per deal this month vs last month?
6. What one change would have the biggest impact on next month's numbers?
7. Am I on track for the 90-day target?

## 90-Day Goal Framework

### Quarter 1 Target (Typical new sourcer)
- Goal: First 2 deals completed, £6,000-£9,000 revenue
- Secondary goal: 10+ investors on database, consistent deal flow

### Quarter 2 Target
- Goal: 2 deals/month, £6,000-£9,000 MRR
- Secondary goal: First recurring income (R2R or management)

### Quarter 3 Target
- Goal: 3 deals/month, £10,000+ MRR
- Secondary goal: Systems documented, considering first VA/employee

### Quarter 4 Target
- Goal: Sustainable £10,000-£15,000/month revenue
- Secondary goal: Multiple income streams, replicated SOPs
