# Security Policy

## Reporting a vulnerability

Email **security@carinaai.uk** with:

- Description of the issue
- Steps to reproduce
- Impact assessment if known

Do not open public GitHub issues for security vulnerabilities.

We aim to respond within 72 hours and provide a fix or mitigation timeline within 14 days for confirmed issues.

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Scope

In scope: Carina agent core, hosted API at app.carinaai.uk, Skills Hub publish validation.

Out of scope: third-party LLM provider APIs, user-supplied skill pack content after publish review.
