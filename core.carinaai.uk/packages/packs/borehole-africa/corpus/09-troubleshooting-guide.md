# Drilling Troubleshooting Guide

## Stuck Drill String

Causes: cave-in above bit, keyseat in soft formation, inadequate circulation.
Actions:
1. Establish circulation if possible; do not pull dry in unstable hole
2. Work pipe up and down with rotation; jarring if available
3. Spot bentonite pill if lost circulation related
4. If freed: consider running casing immediately to stabilise
5. If not freed after safe attempts: consult supervisor; fishing tools may be required

Never exceed rig pull capacity; safety first.

## Lost Circulation

Drilling fluid returns drop or stop. Common in fractured granite or cavernous limestone.
Actions:
- Reduce pump rate; add lost circulation material (LCM) or coarse bentonite
- Drill blind if necessary with air/mist in hard rock
- Case off loss zone if persistent

## Borehole Collapse

Indicators: sudden torque increase, inability to pull tools, no returns.
Actions: stop drilling; run casing if hole is open; re-spud adjacent if hole is lost.

## Artesian Flow

Water flows to surface under natural pressure.
Actions:
- Install blowout preventer or cap during drilling
- Plan head works for controlled discharge
- Notify client and CWSA; may indicate strong aquifer (positive for yield)

## Slow Penetration

Check: bit wear, wrong bit type for formation, insufficient weight on bit,
compressor output (air rigs), or dull hammer (DTH).
Replace bit or switch method after formation identification.

## Contaminated Samples

Milky returns after static period may indicate poor development.
Develop with surging and pumping until turbidity under 5 NTU.
