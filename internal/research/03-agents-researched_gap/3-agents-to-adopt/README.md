# Three Source Agents Reuse Notice

This folder contains the source trees used to study Hermes, OpenClaw, and Odysseus.

Carina rule:
- adopt behavior, not wording
- rewrite prompts, labels, comments, UI copy, and docs in Carina voice
- keep only the exact text required by a license, API, protocol, or file format
- if copied text reads like the source project, rewrite it before shipping
- when Carina gains a new feature, update the shared feature guidance in code and docs so Carina can teach users how to use it without exposing internal architecture or sensitive implementation detail

This folder is reference material for gap analysis and prompt design. It is not a template to mirror verbatim.
