# CARINA AI

## Landing Page Redesign Specification v2.0

### Vision

Carina should no longer be presented as:

* An AI assistant
* An AI framework
* An AI agent toolkit
* Another ChatGPT alternative

Carina should be presented as:

# The Operating System for Knowledge Work

A persistent intelligence layer that connects memory, tools, channels, documents, workflows, models, and skills into one continuously improving system.

---

# Core Problem

Today's work is fragmented.

Users operate across:

* Email
* WhatsApp
* Slack
* Discord
* Telegram
* Documents
* Notes
* Calendars
* Research tools
* AI assistants

Every system is disconnected.

Every conversation starts from zero.

Knowledge is scattered.

Context is lost.

AI forgets.

People repeat themselves.

---

# Core Value Proposition

Carina creates:

## One Memory

Shared across everything.

## One Agent

Available everywhere.

## One Intelligence Layer

Continuously learning and improving.

---

# Product Tagline (all brand applications)

One Memory. One Agent. Everywhere.

NOT: "Intelligence. Connected. Evolving." - that is too abstract and could describe any AI product. The tagline must make a specific promise.

# Success Criteria

A first-time visitor should understand within 10 seconds:

1. What Carina is
2. Why it matters
3. How it is different
4. Why they should care

Without reading documentation.

Without scrolling extensively.

Without understanding AI infrastructure.

Lead with the pain:

"Your work lives in 20 apps. Your intelligence shouldn't."

Then use the screenshots (Workspace, Learning Loop, Channels, Scout) as evidence that Carina solves that problem. The Learning Loop is the strongest story because it is the moat. Everything else is proof.
