# What is Carina?

Carina is an autonomous AI agent platform built by VERLOX Ltd. She executes tasks with real tools, remembers context across sessions, and improves via self-written skills.

## Key capabilities

- **Persistent memory** with PostgreSQL + pgvector semantic search
- **Self-writing skills** that capture solved problems for future sessions
- **Real tool execution**: web search, files, shell (sandboxed), email, HTTP, code, browser, MCP, and more
- **Provider flexibility**: 23 registered providers (cloud and local Ollama/LM Studio) with mid-session switching
- **16 optional domain skill packs** (engineering, finance, healthcare, legal, property, devops, and more)
- **Multi-channel gateways**: 18 channel adapters (CLI, web, Telegram, Discord, Slack, WhatsApp, SMS, Signal, Matrix, Email, and more; config-dependent)
- **Labyrinth Scout** (optional): enterprise security control plane with prompt injection detection and kill switch
