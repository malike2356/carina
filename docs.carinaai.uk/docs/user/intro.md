# What is Carina?

Carina is an autonomous AI agent platform built by VERLOX Ltd. She gets work done on your stack with real tools, remembers context across sessions, and improves via self-written skills when enabled.

For the full product inventory (shipped vs configured vs optional), see the **[capability inventory](/docs/capabilities)**.

## Choose your path

| Path | Best for |
|---|---|
| [Carina Cloud](/docs/user/carina-cloud) | Browser workspace, BYOK keys, hosted billing |
| [Self-hosted install](/docs/user/getting-started) | Full control, npm or Docker on your VPS |
| [Developer guide](/docs/developer/intro) | Extending tools, gateways, skill packs, and integrations |

Carina is the adoption surface. Scout is the paid security layer you add when the work moves from personal use to client-facing or compliance-sensitive deployments. Self-hosted Carina is the MIT entry point; hosted Carina and Scout are where the commercial story starts.
