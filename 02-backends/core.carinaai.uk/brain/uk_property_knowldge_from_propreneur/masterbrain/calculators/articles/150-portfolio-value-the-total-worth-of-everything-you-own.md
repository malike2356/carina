# Portfolio Value: The Total Worth of Everything You Own

Published: Wed, 20 Oct 2027 09:00:00 +0000
Category: Calculations
Slug: portfolio-value-the-total-worth-of-everything-you-own

---

Portfolio value is the sum of what all your properties would sell for in the current market. It sounds simple, but it needs to be updated regularly because property values change. A portfolio that was worth £1 million two years ago might be worth more or less today.\n\nTo calculate portfolio value accurately, you need current valuations, not purchase prices. If you bought a property for £200,000 five years ago and it is now worth £260,000, the portfolio value should reflect £260,000, not £200,000. Using purchase prices understates your true portfolio value.\n
Portfolio value is the denominator in many important ratios including portfolio LTV and portfolio yield. If your valuations are stale, your ratios are unreliable. Update valuations annually using recent comparable sales or professional valuations.

**The formula**

```
Portfolio Value = Σ(Individual Property Values)
```

**Why this matters**

Portfolio value must be based on current valuations, not purchase prices. Update it annually. Stale valuations give you misleading portfolio LTV and yield numbers.
