# IRR: Internal Rate of Return -- The Annualised Return That Accounts for Timing

Published: Mon, 23 Aug 2027 09:00:00 +0000
Category: Calculations
Slug: irr-internal-rate-of-return-the-annualised-return-that-accounts-for-ti

---

IRR is the discount rate that makes the NPV of an investment equal to zero. In plain English, it is the annualised return the investment generates, accounting for the timing of every cashflow. A 12% IRR means the investment generates a 12% annualised return over its life.\n\nIRR is useful because it combines the return and the timing into a single number. A flip that returns 20% in six months has a much higher IRR than a BTL that returns 20% over five years. IRR captures this difference.\n\nFor our BTL example, the IRR might be 9.5%. That means the property generates an annualised return of 9.5% over the ten-year hold period, accounting for both income and capital growth. Compare that to other investments. If a stock market index fund averages 8% over the same period, the property is winning by 1.5%.\n\nIRR has one weakness. It assumes that interim cashflows can be reinvested at the same rate. If the IRR is 9.5% but you cannot reinvest interim cashflows at 9.5%, the actual return will be lower. This is where Modified IRR (MIRR) provides a more realistic picture.\n
Use IRR to compare different investment opportunities. The investment with the highest IRR is generally the best use of your capital, assuming comparable risk.

**The formula**

```
0 = Σ[CF(t) / (1 + IRR)^t]  for t = 0 to n
```

**Why this matters**

IRR is the most widely used metric for comparing investment returns. It accounts for the timing of cashflows. A higher IRR means better use of your capital. Compare IRR across different investment opportunities.
