# Average Yield Weighted: The Honest Way to Calculate Portfolio Performance

A simple average of your property yields is misleading because larger properties contribute more to your income. A weighted average accounts for each property's value. It is the correct way to measure portfolio yield.\n\nIf you have a £500,000 property yielding 4% and a £100,000 property yielding 8%, the simple average yield is 6%. But the weighted average yield is (500,000 times 0.04 plus 100,000 times 0.08) divided by 600,000, which equals 4.67%. The larger property dominates the portfolio yield.\n\nWeighted average is the correct metric for portfolio analysis. It tells you the actual income return on your total capital. Use it for portfolio net yield, portfolio LTV, and any other ratio that involves property values.

**The formula**

```
Weighted Avg Yield (%) = Σ(Property Value × Property Yield) / Total Portfolio Value
```

**Why this matters**

Weighted average yield is the correct way to measure portfolio performance. It accounts for each property's size. A simple average overstates the impact of smaller properties.
