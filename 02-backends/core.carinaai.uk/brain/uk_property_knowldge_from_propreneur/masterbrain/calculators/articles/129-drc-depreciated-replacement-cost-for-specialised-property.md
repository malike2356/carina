# DRC: Depreciated Replacement Cost for Specialised Property

Published: Mon, 09 Aug 2027 09:00:00 +0000
Category: Calculations
Slug: drc-depreciated-replacement-cost-for-specialised-property

---

Depreciated Replacement Cost is used for properties that rarely trade and have no comparable sales or reliable income stream. Schools, hospitals, churches, and public buildings are typically valued using DRC.\n\nDRC calculates the cost of rebuilding the property from scratch, then deducts depreciation for age, wear and tear, and obsolescence. The result is the value of the building. The land value is added separately.\n\nFor a community hall in Portsmouth built in 1980, the replacement cost might be £500,000. Depreciation at 1.5% per year over 45 years is roughly 55%, giving a depreciated building value of £225,000. The land value is £200,000. The total DRC value is £425,000.\n\nDRC is rarely used for investment properties because it ignores income. A building that costs £500,000 to replace might only generate £20,000 in rent, giving a yield of 4%. An investor would pay less than the DRC value because the income does not justify the cost.\n
DRC is primarily a valuation method for insurance and accounting purposes, not investment decision-making. If you are buying a standard income-producing property, use the comparable or investment method instead.

**The formula**

```
Value = Replacement Cost of Building - Accumulated Depreciation + Land Value
```

**Why this matters**

DRC is used for specialised properties that rarely trade. It is based on replacement cost minus depreciation, not income. For most investment properties, the comparable or investment method is more relevant.
