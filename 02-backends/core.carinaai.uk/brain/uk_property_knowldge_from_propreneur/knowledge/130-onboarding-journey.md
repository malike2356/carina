# Onboarding Journey

**Last updated:** 2026-05-17

## Overview
A guided onboarding experience for new workspace users. Walks through key setup stages - profile, workspace configuration, feature introductions, first property, first deal, and Carina AI assistant - with optional Carina assistance at each step.

## Core Features
- **Guided stage progression** - Step-by-step setup flow with sequential stages
- **Carina AI assistance** - Integrated Carina conversation for AI-guided setup at key stages
- **Skip option** - Each stage can be skipped if not relevant
- **Progress tracking** - Tracks per-stage completion and overall journey status
- **One journey per user** - Created when you first access the workspace

## Onboarding Stages

| Stage | What Happens |
|-------|-------------|
| **Welcome** | Initial introduction and overview of Propreneur |
| **Profile Setup** | Set up your user profile, role, and preferences |
| **Workspace Configuration** | Define your business type and focus areas |
| **Feature Introduction** | Quick overview of key modules (pipeline, CRM, properties) |
| **First Property** | Add your first property (or skip) |
| **First Deal** | Create your first deal/pipeline entry (or skip) |
| **Carina Introduction** | Walkthrough of the AI assistant with a guided conversation |
| **Complete** | Journey finished - dashboard ready |

## Getting Started
The onboarding journey starts automatically when you first access a new workspace. Simply follow the prompts through each stage. You can skip stages you don't need and complete the journey at your own pace.

## Key Workflows

### Completing a stage
Each stage presents an action card with instructions. Complete the required action (e.g., fill in your profile, add a property) and mark the stage as done. Your progress is saved, so you can leave and come back.

### Using Carina during onboarding
Some stages offer a Carina conversation for AI-guided setup. Carina can help you understand options, suggest configurations, and answer questions about how features work.

### Skipping stages
Not ready to add a property yet? Skip the stage and come back later. Skipped stages are tracked so you know what you've deferred. You can revisit skipped items from the main workspace.

### Completing the journey
When all stages are done (or skipped), mark the journey as complete. You'll be redirected to the main dashboard with a welcome modal.

## Business Rules
- One onboarding journey per user - created on first workspace access
- Stages must be completed sequentially (can't skip ahead)
- Each stage can be optionally skipped
- Carina integration available at specific stages
- Per-stage data is saved (completion time, skipped status, answers)
- Journey completion redirects to the main dashboard

## Best Practices
- Complete the full onboarding - it sets you up for success
- Don't skip Carina introduction - understanding the AI assistant saves time later
- Add at least one property during onboarding to see the full workflow
- Fill in your workspace configuration accurately - it drives defaults and suggestions
- Use the Carina chat during onboarding for any questions
