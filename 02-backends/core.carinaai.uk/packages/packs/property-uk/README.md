# @verlox/pack-property

UK property entrepreneurship domain pack for the Carina kernel.

Install:

```bash
npm install @verlox/pack-property
export ACTIVE_SKILL_PACKS=property-uk
```

Or via Hub:

```bash
carina pack install property-uk
carina pack install property-uk --npm
```

Large knowledge corpus: optional `@verlox/pack-property-data` may ship separately if the npm tarball exceeds size limits.
