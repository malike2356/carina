# Commercial boundaries

:::info Canonical inventory
Product boundaries and attestation honesty: [Capability inventory](/docs/capabilities).
:::

Carina core, currently published for users as `carina-agent`, and the Scout client SDK (`@verlox/carina-scout`) are MIT licensed. The scoped `@verlox/carina-core` package name is reserved for a future package split and is not the live public npm install path yet. The Scout server (`console.labyrinthscout.com`) and Carina Ops are commercial. See the [commercial boundaries doc](https://github.com/malike2356/carina-agent/blob/main/docs/kernel/COMMERCIAL_BOUNDARIES.md) in the public repo.

That is the product model: Carina earns adoption, Scout converts the accounts that need governance, audit, and client-facing trust controls.
