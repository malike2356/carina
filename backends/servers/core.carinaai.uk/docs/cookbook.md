# Cookbook (deprecated name)

The user-facing product name is **Playbook**, not Cookbook.

See [Playbook](./playbook.md), especially the **Hardware capability** section, for current documentation.

- Web: `/playbook` ( `/cookbook` redirects here )
- CLI: `carina playbook` ( `carina cookbook` is a deprecated alias )

Internal implementation code may still live under `src/cookbook/`; that is a private module name, not operator-facing language.
