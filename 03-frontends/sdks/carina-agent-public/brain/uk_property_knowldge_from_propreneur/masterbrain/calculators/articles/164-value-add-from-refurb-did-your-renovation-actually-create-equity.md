# Value Add from Refurb: Did Your Renovation Actually Create Equity?

Published: Wed, 08 Dec 2027 09:00:00 +0000
Category: Calculations
Slug: value-add-from-refurb-did-your-renovation-actually-create-equity

---

Value add measures how much equity your refurbishment created. It is the increase in property value minus the cost of the refurb. If you spend £20,000 on a kitchen and bathroom refurb and the property value increases by £30,000, the value add is £10,000. Every pound you spent created 50p of extra equity.\n\nThe value add ratio is the increase in value divided by the refurb cost. A ratio of 1.5 means every £1 spent created £1.50 of value. A ratio below 1.0 means the refurb destroyed value. The refurb cost more than it added.\n\nFor most properties, a value add ratio of 1.5 to 2.0 is achievable for well-chosen refurbishments. Cosmetic improvements typically have higher ratios than structural works. A £5,000 cosmetic refurb that adds £15,000 of value has a ratio of 3.0. A £50,000 structural refurb that adds £70,000 has a ratio of 1.4.\n
Always calculate the expected value add before you start work. If the ratio is below 1.5, question whether the refurb is worth doing. There might be better ways to deploy that capital.

**The formula**

```
Value Add = (New Market Value - Old Market Value) - Refurb Cost
Value Add (%) = Value Add / Refurb Cost × 100
```

**Why this matters**

Value add ratio should be at least 1.5. Below 1.0 means the refurb destroyed value. Cosmetic refurbs typically have higher ratios than structural works. Calculate before you start.
