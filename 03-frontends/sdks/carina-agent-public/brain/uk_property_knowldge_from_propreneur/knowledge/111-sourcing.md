# Deal Sourcing

**Last updated:** 2026-05-17

## Overview
Track and manage deal sourcing workflows - from listing sources like Rightmove and Zoopla to auctions, direct-to-vendor, and wholesale channels. Define sourcing criteria for automated matching, save research links for review, and monitor price changes on watched properties.

## Core Features
- **Listing sources** - Track external portals and channels (Rightmove, Zoopla, OnTheMarket, auctions, agents, wholesalers)
- **Sourcing criteria** - Define deal criteria (price range, bedrooms, postcodes, property types, yield targets, strategy)
- **Automated matching** - New listings are automatically scored against your active criteria
- **Research links** - Bookmark interesting properties for later review, with analysis hints
- **Price monitoring** - Track price reductions on watched properties
- **Source events** - Log new listings, price reductions, sold status, and auction results

## Getting Started
1. Add your listing sources - portals, auction houses, agents, and wholesalers you work with
2. Create sourcing criteria - what makes a deal worth pursuing (price, location, yield)
3. Save research links when you spot interesting properties online
4. Review matched deals against your criteria
5. Push promising matches into deal analysis

## Key Workflows

### Setting up sourcing criteria
Define the parameters that matter: minimum and maximum price, bedroom range, target postcodes (multiple supported), property types, minimum yield percentage, and target strategy. Activate criteria to start receiving matches.

### Saving a research link
Use the bookmarklet or manually enter a property URL, add notes, and optionally set hints for purchase price, bedrooms, and property type. These hints pre-populate deal analysis if you pursue the lead. You can flag links to receive notifications when the property is saved.

### Matching engine
When a new listing arrives from a source, it's automatically scored against all active criteria. Matches appear in your sourcing dashboard for review. You can see which criteria triggered the match and how well the listing scores.

## Business Rules
- Criteria can target multiple postcodes and property types simultaneously
- Active criteria automatically match against incoming listing events
- Research links can be flagged for notification alerts
- Price hints on research links feed into deal analysis prepopulation
- Multiple sourcing criteria can be active simultaneously with different priorities

## Best Practices
- Create separate criteria for each deal strategy (BTL vs flip vs BRR)
- Use broad postcode areas (e.g., first part of the postcode) to catch more opportunities
- Save research links quickly - a browser bookmarklet makes this instant
- Review matches daily for time-sensitive off-market opportunities
- Set realistic yield minimums based on your local market
