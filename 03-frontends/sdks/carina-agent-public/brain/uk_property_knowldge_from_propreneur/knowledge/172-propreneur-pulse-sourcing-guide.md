# Propreneur Pulse - Deal Sourcing Guide (Carina)

Tags: `deal_sourcing`, `calculators`, `sourcing_strategy`

## Sourcing workflow

1. **Find** - portals, auctions, off-market agents, direct-to-vendor.
2. **Analyse** - run the right calculator (BTL, HMO, BRR, SA, development, etc.).
3. **Package** - deal pack PDF, comparables, and investor one-pager.
4. **Present** - CRM track, pipeline stage, and follow-up sequences.

## Calculator selection (21 strategies)

| Strategy | Use when |
|---|---|
| BTL | Single let, long-term hold |
| HMO | Room-by-room rent roll |
| BRR | Add value then refinance |
| SA | Short-term/high nightly income |
| Development | Commercial-to-residential or ground-up |
| Flip | Buy, refurb, sell within 12-18 months |

Carina `run_calculator` and the Deal Calculators hub apply the same maths as the web UI.
