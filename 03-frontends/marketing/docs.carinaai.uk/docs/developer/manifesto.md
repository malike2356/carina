# Manifesto

Carina is the free, self-hosted kernel for building AI agents that can actually do work. It provides tools, memory, channels, model routing, and a skill pack system so you can focus on what your agent does, not how it runs. Built in Portsmouth, UK. MIT licensed. Free forever. Educators can use the [University program](/docs/developer/university-program) for coursework and dissertations.

Scout is the commercial governance layer for production agents: injection protection, approvals, audit trails, kill switch, and compliance exports. [Carina Cloud](https://carinaai.uk/cloud) is the hosted browser workspace (paid hosting plus Ops plans). Carina Ops adds team BYOK, workbench, and audit on Cloud. Products like Propreneur, Flitz, COMPASS, and ABBIS are distros built on the kernel.

The full manifesto lives in the repository root:

**[Read the full manifesto on GitHub](https://github.com/malike2356/carina-mutant/blob/main/MANIFESTO.md)**

Quick start:

```bash
npm install -g carina-agent
carina setup
```

Then try [Carina Cloud](https://carinaai.uk/cloud) or read [Build your first domain pack](/docs/developer/first-domain-pack) or [Skill packs](/docs/developer/skills/packs).
