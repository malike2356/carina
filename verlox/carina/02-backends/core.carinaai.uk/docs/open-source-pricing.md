# Source release + Scout pricing model

## What is MIT licensed

Carina core (`core.carinaai.uk`) is MIT licensed. Public repository release is a distribution step; review private operational files and secrets before switching repository visibility.

## What is commercial

| Product | License | Includes |
|---|---|---|
| Labyrinth Scout | Commercial subscription | Security console, kill switch, anomaly detection, compliance exports |
| On-chain attestations | Scout Enterprise add-on | ERC-8004 identity, Agent Trust attestations, ERC-8126 verification when configured |
| Carina Cloud | Hosted subscription | Managed Carina + Scout pairing, Stripe billing, tenant dashboard |

## Recommended tiers

| Tier | Price guide | Attestation frequency |
|---|---|---|
| Scout Standard | Self-serve Stripe checkout | Weekly |
| Carina + Scout Bundle | Bundle checkout on app.carinaai.uk | Weekly |
| Enterprise | Sales-assisted | Daily (configurable in account dashboard) |

Carina source remains free after release. Revenue comes from Scout supervision, hosted operations, and on-chain trust services.
