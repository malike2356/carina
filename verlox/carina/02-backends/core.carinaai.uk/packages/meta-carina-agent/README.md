# Carina agent meta-package

Installs the [@verlox/carina-core](https://www.npmjs.com/package/@verlox/carina-core) kernel.

```bash
npm install -g carina-agent
carina --version
```

During the 0.2.x transition, `carina-agent` is a thin wrapper around `@verlox/carina-core`. Prefer `@verlox/carina-core` for new integrations.

Domain packs are optional. Install via Hub or `carina packs enable <name>` after setup.

See [README.cli.md](../../README.cli.md) in `@verlox/carina-core` for full CLI documentation.
