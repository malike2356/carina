# Prompt 05: Distro Module Scaffolder

## Context

A distro is composed of modules. A module is a standalone unit that adds domain-specific
capability: schema (data models), routes (API endpoints), service (business logic),
workflows (automated sequences), skills (Carina skills using the module's tools), and
ui (React components for the web panel).

The module scaffolder generates the complete file tree for a new module so developers
start from a consistent, working template.

## What to Build

### 1. `carina distro module add`

```bash
carina distro add case-management
```

Generates:
```
modules/case-management/
  schema.sql                  - table definitions
  routes.ts                   - Express routes
  service.ts                  - business logic
  workflows/
    case-opened.ts            - triggered on new case
  skills/
    case-lookup.ts            - Carina skill: find a case
  ui/
    CasePanel.tsx             - React component for workspace panel
  index.ts                    - module entry point
  README.md
```

### 2. Generated schema.sql template

```sql
-- Module: case-management
-- Generated by: carina distro add case-management

CREATE TABLE IF NOT EXISTS cm_cases (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES organizations(id) ON DELETE CASCADE,
  reference TEXT NOT NULL,
  title TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'open',  -- open | in-progress | closed
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX ON cm_cases (tenant_id);
CREATE INDEX ON cm_cases (status);
CREATE INDEX ON cm_cases (reference);
```

### 3. Generated routes.ts template

```typescript
import { Router } from 'express';
import { CaseManagementService } from './service';

const router = Router();
const svc = new CaseManagementService();

// GET /api/modules/case-management/cases
router.get('/cases', async (req, res) => {
  const cases = await svc.list(req.tenantId!, req.query);
  res.json(cases);
});

// POST /api/modules/case-management/cases
router.post('/cases', async (req, res) => {
  const caseRecord = await svc.create(req.tenantId!, req.body);
  res.status(201).json(caseRecord);
});

// PATCH /api/modules/case-management/cases/:id
router.patch('/cases/:id', async (req, res) => {
  const updated = await svc.update(req.tenantId!, req.params.id, req.body);
  res.json(updated);
});

export { router as caseManagementRoutes };
```

### 4. Generated skill template

```typescript
// modules/case-management/skills/case-lookup.ts
import { defineSkill } from '@verlox/carina-sdk';

export default defineSkill({
  name: 'case-lookup',
  description: 'Look up a case by reference number or keyword',
  parameters: {
    query: { type: 'string', description: 'Reference number or keyword to search for' },
  },
  async execute({ query, tenantId }) {
    const resp = await carinaHttp.get('/api/modules/case-management/cases', {
      params: { q: query, tenantId },
    });
    return resp.data;
  },
});
```

### 5. Module registration in distro

After generating the module, the scaffolder updates `carina.distro.json` to include
the new module:
```json
{
  "modules": [
    { "id": "case-management", "path": "./modules/case-management/index.ts" }
  ]
}
```

And `modules/case-management/index.ts` exports all the module's exports:
```typescript
export { caseManagementRoutes } from './routes';
export * from './service';
export { schema } from './schema.sql';
```

## Verification Checklist

- [ ] `carina distro add case-management` creates all 8 files in the correct structure
- [ ] Generated `schema.sql` has valid SQL (run through psql syntax check)
- [ ] Generated `routes.ts` compiles with TypeScript without errors
- [ ] Generated skill file can be loaded by `carina skills validate`
- [ ] `carina.distro.json` is updated with the new module reference after scaffolding
