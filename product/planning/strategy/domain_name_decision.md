    - Documentation screenshots and copy-paste examples. Every blog post, every README in a forked repo, every Discord answer where someone pasted curl carinaai.uk/... -- those live forever. The redirect catches most of them. What it does not catch is the mental association.

    One config value. Every component reads it. Nothing hardcodes the domain.


    CARINA_BASE_URL=https://carinaai.com
